# Contributing

Use this template on a real project first. Then open an issue.

Please include:
- Product type (video / ERP / commerce / other)
- Cursor Project or Codex
- Which rule helped
- Which rule made the agent drift or bloated STATUS

Pull requests:
- Keep `AGENTS.md` short
- Keep `STATUS.md` to one page
- Do not add a second progress file
- Guides live in `README.md`. Do not translate the operating files; those stay English.
